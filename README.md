# Sistema de cadastro e beneficação de novos colaboradores

## Descrição

Sistema responsavel pelo cadastro de novos colaboradores. No sistema, deverá ser informado o nome do colaborador e seu respectivo salario. O sistema deverá retornar uma mensagem de boas vindas deixando o colaborador e o seu salario base juntamente com o seu salario bonificado com 15%


## funcionalidades

Cadastro do cargo do funcionário;
Cadastro do salário-base;
Cálculo automático do bônus de boas-vindas de 15%;
Cálculo do salário final com o bônus;
Exibição dos dados cadastrados;
Exibição do valor do bônus;
Exibição do salário final após a bonificação.


## como funciona 

O funcionamento do sistema será realizado de seguinte forma:

O usuário acessará o sistema de cadastro.
Será solicitado o nome do colaborador.
Em seguida, será solicitado o cargo do colaborador.
O usuário deverá informar o salário-base.
O sistema calculará automaticamente o bônus de boas-vindas correspondente a 15% do salário-base.
O sistema somará o bônus ao salário-base para obter o salário final bonificado.


## resultado esperado
O sistema deverá permitir que a empresa cadastre novos colaboradores de maneira simples e rápida, realizando automaticamente o cálculo da bonificação de 15% e apresentando de forma clara o salário-base, o valor do bônus e o salário final do funcionário.
